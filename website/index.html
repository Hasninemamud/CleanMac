Built for clarity, not fear

Five focused areas. No malware theater. No “RAM booster.”

Clean

Junk caches & logs, leftover DMG/PKG installers, and rebuildable project folders like node_modules and DerivedData.

Apps

Scan /Applications leftovers across Library folders and surface orphaned data from apps you already removed.

Analyze

Disk map of your home volume, files ≥50 MB, and duplicates verified by size then SHA-256.

Optimize

Optional maintenance — DNS flush, Spotlight reindex, Finder relaunch — preview first, confirm before run.

Status

Live meters for load, memory, and disk with a short history sparkline. Refresh every few seconds.

Native stack

SwiftUI shell drives a Go CLI kernel over JSON. Fast scans, no Electron bloat, light & dark chrome.

Safety by default

Review first. Trash only. System paths stay out of reach.

  • Trash only — selections go to the macOS Trash via Finder APIs, never silent rm.
  • Safe / Review labels — every item is classified before you select it.
  • Blocked prefixes — /System, /usr, /bin, and other OS paths cannot be deleted.
  • Confirm step — count and byte total shown before anything moves.
  • Local only — no accounts, cloud upload, or telemetry. Scans stay on your Mac.

What we don’t do

Empty Trash for you, secure-erase disks, inject “malware scans,” or promise fake RAM boosts.

How a cleanup works

Three steps. You stay in control the whole time.

  1. 1

    Scan

    CleanMac walks known junk roots, Downloads installers, project trees, and Library leftovers — reporting size as it goes.

  2. 2

    Review

    Pick Safe items in one click, or cherry-pick Review rows. Reveal any path in Finder before you commit.

  3. 3

    Trash

    Confirm the selection. Nested paths collapse so you don’t double-delete. Undo from Trash like any other file.
